## Publish with GitHub Pages
1. Create a repository named `alex-kilonzo-portfolio` (or use your GitHub username repository for a root site).
2. Upload all files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the displayed URL.

Image filenames are case-sensitive. Keep the image names exactly as referenced in `index.html`.
